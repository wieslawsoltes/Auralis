# Auralis Studio 0.4 — implementation and qualification boundaries

This matrix describes actual behavior. It does not claim complete WaveLab parity, Dolby authorization, external loudness certification, arbitrary native plug-in compatibility, or enterprise certification.

| Requested area | Implemented behavior | Material boundary |
|---|---|---|
| Native CLAP | Linux native effect host with offline processing, parameter events, latency compensation and X11 embedded editor; state envelope, GUI callbacks, timer/FD support, allowlisted descriptor selection; editor gesture→save→reopen→render fixture passed | One mono/stereo main input/output bus; no instruments/MIDI, catalog scanner or dynamic bus changes. No commercial plug-in matrix. OS process separation is not a security sandbox. |
| Native VST3 | Linux processor and separate-controller lifecycle, connection messages/attributes, saved component/controller state, X11 editor with run-loop callbacks, focus/key/resize handling, offline processing and latency compensation; editor state/render and plug-in resize fixtures passed | Module binary path required; stereo/mono main bus only. No Windows/macOS VST3 loaders, instruments, sidechains or broad third-party compatibility qualification. |
| Audio Units | AUv 2 effect host source for macOS AudioToolbox, planar PCM, callback, sample timestamps, latency compensation | Not compiled or executed on this Linux runner. AUv 3 asynchronous hosting is not implemented. |
| ADM / immersive output | BS.2076-2 Objects metadata, independent PCM object channels, CHNA, RIFF or BW64/ds 64, 24-bit 48/96 kHz; browser exports two objects per populated track | Generic ADM, not a Dolby Atmos encoder or renderer. No Dolby profile certification, bed/object automation editor, binaural metadata authoring, or Atmos licensing. UI limit: 16 objects/256 MB PCM. Module limit: 64 objects; in-memory writer below 4 GiB. |
| CD / DDP | CD 44.1 kHz/16-bit stereo mastering, 588-frame sector padding, rounded marker/PQ track starts, ISRC/UPC checks, WAV+CUE ZIP; standalone DDP 2.0 invokes configured cue2ddp then ddpinfo verification | External DDP binaries are not redistributed. Obtain them from their author and configure paths. CD-Text for that encoder is Latin 1. No optical-drive burning, all PQ/index variants, pressing-plant approval or independent-vendor DDP certification. |
| Spectral restoration | Noise-profile reduction, spectral gate/attenuation/interpolation, declick and predictive healing; rectangle/lasso/brush masks with add/subtract and mask undo; actual per-bin mask processing | 128 shapes / 4,096 points. Hard mask edges at FFT resolution. No magic wand, spectral clipboard, semantic reconstruction or full commercial restoration-suite parity. Healing ≤200 ms; interpolation ≤500 ms. |
| Time / pitch | Stereo-coherent WSOLA, windowed-sinc pitch resampling, fractional-lag YIN, sustained monophonic note correction, exact output lengths and terminal-window preservation | UI stretch 0.5–2×, pitch ±12 semitones. Module accepts wider 0.25–4×/±24 but quality is not broadly qualified there. No formant preservation, polyphonic correction, tempo map or continuous automatic vocal tuning. |
| Metering / delivery | Streaming K-weighting/two-stage gates, integrated LUFS, continuous momentary/short-term maxima, LRA, eight-phase true peak; linked normalization constrained by peak; encoded WAV remeasurement and pass/fail JSON report | 318 assertions from supported EBU v5 fixtures passed. Two multichannel fixtures are unsupported. Passing fixtures is not external certification. Delivery uses constant linked gain, not an oversampled dynamic limiter. A loudness target may remain unmet to respect peak ceiling. |
| Large sessions | Random-access local/HTTP WAV providers; bounded reads and waveform index; scheduled block playback; continuous DSP block export;2 MiB immutable chunk uploads and range responses; 3-hour/1.04 GB fixture test | Sources/arrangement up to 24 h; RIFF input below 4 GiB; stereo. Indexing still reads every source frame once. Peak index and compact loudness history grow with duration. Full-file spectral edits have 96 MB working guard. Verified true-peak delivery currently requires resident PCM. |
| Collaborative merging | Server-authoritative three-way merge from retained base; independent fields/IDs; atomic clip source/timing groups; track order; tombstones; durable overlap proposal; field-level resolution; idempotent successful operations; CAS-protected history/audit | Saves trigger merge, not keystroke/audio co-edit streaming or CRDT. Conflicting proposal submissions can create duplicate proposals on retry. Project versions/tombstones are retained without automatic pruning. Merged saves clear local whole-document undo history to avoid undoing remote work. |
| Collaboration transport | SSE session notifications with revocation checks; reconnecting 25-second streams; 15-second cursor-presence refresh | The SSE backend checks the database once per second. This is not a push-native Durable Object/WebSocket coordination service. Cross-account hosted browser collaboration was not qualified. |
| Administration / security | Owner/editor/commenter/viewer permissions, member role change/revocation, archive/reopen, configurable quota, hashed expiring single-use invitations and revocation, append-only API audit export, trusted hosted identities, origin checks, immutable source identities; commit-time auth rechecks | Project administration, not a complete enterprise organization system. No SCIM/SAML implementation, independent MFA, tenant policy management, legal holds, KMS/BYOK, SIEM connector, penetration test, immutable external audit anchoring, disaster-recovery certification, backups UI, or automated expired-upload garbage collection. |
| WebGPU / browser engine | Instanced GPU waveform bars, accurate cached PCM bounds, indexed streaming waveforms, Canvas fallback; AudioWorklet when available, explicit legacy main-thread audio fallback on insecure preview origins | Physical GPU execution was not available in the tested HTTP cloud browser. FFT/index aggregation remains CPU-side. Legacy ScriptProcessor fallback is less robust under main-thread load. |
| Hardware / production qualification | Browser edit/gesture/linked-window tests; numerical and native tests; Xvfb native editor gestures; 512 HTTP commits, 32 SSE observers, chunk/range integrity, killed-process restart and a 60-second concurrent-read soak; runnable GPU/input checks | Xvfb is virtual. No physical GPU/interface/analog loopback, ASIO/CoreAudio driver qualification, multi-hour playback, distributed production load, independent security audit or enterprise SLA certification. |

## Workspace coverage

The 0.4 interface includes contextual ribbons, command search, an ordered insert rack, native editor controls, multiselect/ripple tools, lasso/brush masks and detachable linked windows. An optional Electron launcher hosts the same interface in native application windows. [WORKSPACE.md](WORKSPACE.md) maps every workspace area and lists the remaining UI parity boundaries.

## Practical limits

- Up to 64 ordered inserts; native state envelopes up to 190,000 bytes each, subject to the total 1 MB project document limit.
- 64 tracks, 2,000 clips, 200 project source records, 1,000 markers; timeline/source metadata up to 24 h.
- Non-WAV browser-decoded imports:100 MiB compressed input and 30-minute decode guard. Large WAV import uses the provider above 32 MiB.
- Resident imports retain the 384 MiB decoded-audio guard; edit/export copies and undo source retention can raise total process memory above it.
- Ordinary immutable upload≤48 MiB; provider uploads use 2 MiB chunks, reserved quota and validated completion. Default project storage quota 512 MiB; owner-adjustable 1 MiB–20 GiB. Quota and identity enforcement are tested locally, not certified under a distributed failure model.
- Standard rendered Blob download is bounded at 128 MiB when provider audio is present. Larger output uses a writable file sink on a supported secure Chromium origin. RIFF output remains below 4 GiB.
- Streaming playback schedules 1.5 seconds ahead. It reports buffering and shifts the transport time base on starvation; this does not establish glitch-free performance under browser suspension.
- Native browser handoff is limited to 96 MiB; native CLI processing reads/writes blocks. Plug-in latency up to 10 seconds is compensated. Effect tail beyond the source duration requires explicit trailing silence.
