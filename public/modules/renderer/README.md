# @auralis/renderer

Version 0.3.0. ESM module; no runtime dependencies. MIT licensed.

Pack independently with `npm pack` in this directory. See `index.d.ts` for the public API. The complete Auralis Studio repository includes examples, numerical tests, and a capability/validation report.

WaveformRenderer(host) selects WebGPU when available and falls back to Canvas 2D. Provide a positive host height, call setScene(), then drawCursor(time). Labels and guides use Canvas; waveform bars use the GPU. Call destroy() on disposal.

Scene options include amplitude zoom, montage track offset, time selection and frequency-selection overlays. Resident Float32Array channels and streamed PeakChannel descriptors are supported. Public host/base/gpu/overlay elements support custom layer composition.

`spectral: true` controls the frequency-selection overlay only. The Studio's spectrogram pixels are generated by its audio worker and composed as a separate canvas. The renderer package does not contain a spectrogram generator.
